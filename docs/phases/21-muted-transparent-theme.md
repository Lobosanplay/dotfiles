# Phase 21 — Muted, translucent desktop theme

## Objective

Adapt the subdued colors and restrained transparency of 43PR's dotfiles to
the existing Fedora, Hyprland, DMS, GTK, and Kitty setup. Keep DMS/Quickshell
as the shell and preserve the user's custom DMS theme selection and unrelated
settings.

## Design

- The semantic Graphite palette is shifted from bright blue/mint accents to
  low-saturation slate tones. Semantic status colors remain distinct but are
  softened.
- DMS/Matugen uses the native `scheme-neutral` generator for wallpaper-derived
  GTK, Kitty, and Hyprland colors. The custom Graphite Slate DMS theme remains
  selected as its stable shell palette and fallback.
- DankBar background alpha is set to 0.74 and widget alpha to 0.92. Kitty
  receives a small repository-owned include setting its background opacity to
  0.92; its existing font, keybindings, and blur configuration stay user-owned.
- Hyprland keeps its existing blur, rounding, gaps, and shadows. Window opacity
  is only slightly reduced (active 0.98, inactive 0.94) for a restrained glass
  effect.
- GTK3 and GTK4 prefer dark styling and retain the existing icon theme.
- Existing DMS popup and floating-window transparency settings are preserved.

## Reversibility

Restore the pre-change active files from their numbered `.before-phase21`
backups. The GTK settings are repository-managed links. Remove the Kitty
`include dotfiles-theme.conf` line and its link to revert its transparency
without replacing `kitty.conf`. DMS settings were saved by the existing profile
applier to `settings.json.before-phase20.4`; the former
`dotfiles-graphite-blue` custom theme directory was left intact.

## Validation

- `python3 -B scripts/build-theme.py --check`: passed.
- `python3 -B -m unittest discover -s tests/theme -v`: all 17 tests passed.
- `python3 -B scripts/apply_dankbar_preset.py --check`: passed after DMS restart.
- DMS Matugen generated the current wallpaper palette with
  `scheme-neutral`; its GTK CSS, Kitty colors, and Hyprland color module were
  regenerated. DMS service is active.
- `hyprctl configerrors`: empty before and after `hyprctl reload`; reload
  returned `ok`.
- GTK3/GTK4 settings resolve to the repository files. Kitty's existing config
  includes the linked opacity fragment.
- Existing `popupTransparency` (0.31) and all other unrelated DMS preferences
  were preserved.
- `git diff --check`: passed.

## Limitations

Visual equivalence is approximate: 43PR uses its own Quickshell styling while
this project uses DMS's native theme and bar controls. Application-level GTK
and Kitty theme output remains generated by DMS/Matugen.

The validated semantic `dynamic-colors.json` export is not directly consumed
by active Hyprland; DMS's regenerated `dms.colors.lua` supplies its live
wallpaper-derived border colors. This phase did not add a second dynamic-theme
loader.
